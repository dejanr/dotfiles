# Dotfiles

This context defines the language used to describe the computers and configuration managed by this repository.

## Language

**Host**:
A named computer whose system and user environment are managed by this repository.
_Avoid_: Host configuration, when referring to the computer itself

**Host configuration**:
The machine-specific choices applied to one or more hosts. A host commonly has its own configuration, while equivalent hosts may share one.
_Avoid_: Host, machine configuration
